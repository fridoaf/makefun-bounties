Ember Pact — Duel of the Four Suits: an original card game where you duel the AI Warden across four suits, playing cards from your hand to the table to win rounds and claim the pact.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser and play with mouse and keyboard. The game itself is plain static files under game/ — any static server will do.
