# The joke about the demo

One-line joke about working beside AI coding agents.

`main.py` (Python 3.13) writes the joke to `/output/entry.txt`: UTF-8,
one line, 1–280 characters. It creates `/output` if needed and sets the
output file to mode 0644. Deterministic — the text is a fixed string.

## Entry

> I let my agent run the demo; it fixed the bug, fielded the questions, and now the team thinks I'm its intern.
